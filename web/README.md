# Frontend - Diatinf X

Este diretório será usado para a aplicação web do projeto Diatinf X.

## Objetivo
- Implementar a interface mobile-first e desktop.
- Consumir a API RESTful do backend.
- Gerenciar autenticação, feed, comentários, avaliações e estatísticas.

## Estrutura esperada
- componentes
- páginas
- hooks
- services
- styles

## Execução

```bash
npm install
npm run dev
```
